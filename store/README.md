# Store drafts for the CleanYourTV launcher

These pages are preparation for a possible Google Play and Samsung Galaxy Store listing of the
**launcher** in this repo (`com.gathin.tvhome`, version 2.8). Nothing here was uploaded.

This is not the separate community phone app (`tv.cleanyour.app`), which connects to a TV over ADB.
That app is not in this repository and these drafts do not describe it.

| File | What it is |
|---|---|
| [PLAY.md](PLAY.md) | Verdict, policy findings, and what is still Martin’s to decide |
| [listing-en.md](listing-en.md) | English Play listing |
| [listing-cs.md](listing-cs.md) | Czech Play listing |
| [data-safety.md](data-safety.md) | Data safety form answers |
| [content-rating.md](content-rating.md) | Content rating questionnaire |
| [privacy-policy-en.md](privacy-policy-en.md) | Privacy policy to host at a public HTTPS URL |
| [privacy-policy-cs.md](privacy-policy-cs.md) | Czech privacy policy |

The same privacy policy text is shown inside the launcher (Launcher settings → Privacy policy).
Host the English page, put that URL in Play Console, and keep the in-app text in step with it.
